# Power BI MCP Server with Claude

Build a full semantic model by chatting with Claude: tables, Date table, relationships and earned-value DAX

Video link coming soon. · **[Download everything as one zip](https://github.com/NextGenBIGuru/downloads/raw/main/zips/Power%20BI%20MCP%20Server%20with%20Claude.zip)**

All data here is made up for teaching. There is no client or company data.

## What's inside

| Item | What it is |
|---|---|
| `Construction Portfolio.pbip` | The Power BI project (PBIP). Open this file in Power BI Desktop |
| `data/` | The CSV files the model loads |
| `prompt-pack.md` | Every prompt from the video, in the order used |

## Before you open it

1. Unzip into `C:\NextGenBIGuru\`, so the data sits in `C:\NextGenBIGuru\Power BI MCP Server with Claude\data\`.
2. Using another folder? In Power BI Desktop: Transform data, then Manage parameters, and set **DataFolder** to your `data` folder, written the same way as the current value (no backslash at the end). Then Refresh.
